Связь между *Frontend* и *Backend*.
# Связи
SSE-соединение:
	Связь для отправки уведомлений о событии в real-time. Подробнее Frontend [[-]], Backend: [[SSE]].
REST-API:
	Реализует запросы. Подробнее Frontend [[-]], Backend: [[API]].

# Поддержка

Для безопасности большинство запросов требуют токен аунтификации в заголовке, который хранится в cookie сайта, и получается от сервера после авторизации.

Для создания защищенного режима используется certbot:
```
sudo certbot --nginx -d example.com -d www.example.com
```

Для разделения запросов используется Nginx
